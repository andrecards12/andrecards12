# André Cardoso

Desenvolvedor de software focado em criar produtos que combinam inteligência
artificial, automação, segurança e experiências web.

Atualmente desenvolvo soluções para o setor jurídico e ferramentas locais
orientadas por IA, com atenção especial à privacidade, usabilidade e aplicações
práticas.

## Em desenvolvimento

- **LexQuest** - plataforma de preparação para a OAB com simulados, banco de
  questões, acompanhamento de desempenho e explicações assistidas por IA.
- **JARVIS 2.0** - assistente local em português com LLMs, voz, automação,
  integração com Home Assistant e recursos jurídicos.
- **LexAuth** - ferramentas de autenticação e segurança voltadas ao ecossistema
  jurídico.
- **GitHub Profile Insights** - visualização e análise de dados de perfis e
  repositórios.

## Tecnologias

`Prisma` `Tailwind CSS` `Cloudflare` `Docker` `Git`
